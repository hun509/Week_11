기능 2 · 호스트 전용

AWS S3 음원 목록 선택 & 재생 제어

S3 버킷의 음원 목록을 불러와 선택하면 방 전체 게스트에게 즉시 동기화됩니다. 위 플레이어에서 일시정지/탐색을 눌러도 게스트 화면에 자동 반영됩니다.

기능 1(입장) · 기능 3(댓글) 이용 가능

현재 게스트로 참여 중입니다. 선곡·재생·일시정지·구간 이동(기능 2)은 이 방의 호스트(DJ)만 제어할 수 있으며, 호스트가 조작하면 내 플레이어도 자동으로 동기화됩니다.

기능 1에서 설정한 닉네임(미설정)으로 등록되며, 실제 시각(KST)과 곡 재생 시점이 함께 기록됩니다.
